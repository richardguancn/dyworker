# Native Pages

Use this workflow after [output format selection](../../shared/output-and-template-handling.md#output-format-selection) chooses an available, authorized Spaces destination. Follow the shared [Spaces practices](../../shared/output-and-template-handling.md#spaces) for destination IDs, audience, metadata, scoped instructions, and recovery. Resolve names or links to actual IDs; clarify conflicting matches without requiring a location choice for the personal default. Use the current supported Page creation, editing, visualization, and nesting operations.

Use native Page blocks and returned IDs. Read existing content before editing, keep Page IDs on refresh, and read back the saved blocks, links and embeds. For quantitative visuals, use [visualize-data’s Page convention](../../skills/visualize-data/SKILL.md). Keep the artifact’s own headings, content order and source conventions in its delivery skill.
