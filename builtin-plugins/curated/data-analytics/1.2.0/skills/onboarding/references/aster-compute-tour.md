- **Preview:** append `investigation/index.html?view=1&tab=capacity` to `baseUrl` in the installed [example catalog](../../../assets/example-catalog.json).
- **Follow-up artifact type:** an investigation dashboard.

Introduce the fictional fleet overview and capacity investigation. Invite the user to explore regional capacity pressure and incidents, or filter by region to compare operating conditions. Displayed metrics are demo data, not verified current operational data. Use this context for the introduction without inspecting the site, querying operational systems, or running an analysis. Finish with the shared tour's “Create one with my data” follow-up.
