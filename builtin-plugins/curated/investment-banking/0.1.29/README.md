# Investment Banking

Bring deal context into the work that moves banker workflows forward.

## When to use this plugin

Use Investment Banking when you need banker-owned M&A, capital markets, LevFin, restructuring, valuation, diligence, process execution, buyer and investor targeting, model work, pitch materials, board or deal committee materials, or circulation QC.

Use this plugin for transaction execution and banker work product. Generic company research, generic valuation, generic decks, or generic meeting prep should route elsewhere unless the request explicitly names Investment Banking or clearly describes a banker-owned transaction workflow.

## Get started

Try asking:

`@Investment Banking Help me get started with a first banker task`

The plugin will route through the Investment Banking router, select the focused workflow, and ask for or connect only the source categories needed for that workflow. You can also start directly with deal materials, process updates, counterparty context, market data, existing models, uploaded files, exports, pasted notes, or public evidence.

## Example workflows

| Workflow | Try this | Skill | Result |
| --- | --- | --- | --- |
| Tear down seller materials | `Analyze this CIM and identify diligence gaps, red flags, and model handoffs.` | `cim-teardown` | A banker-readable diligence or auction-readiness report with source posture and next asks |
| Build a buyer or investor list | `Build the buyer universe and first-wave outreach rationale for this sale process.` | `buyer-investor-list` | Ranked counterparties with relationship context, rationale, and follow-up priorities |
| Plan a financing | `Compare ECM, DCM, LevFin, and hybrid financing alternatives for this issuer.` | `capital-markets-issuance` | A financing alternatives view with market evidence, constraints, and recommendation posture |
| Prepare a board or deal committee memo | `Turn the model, diligence findings, and process status into a board-ready transaction memo.` | `memo-builder` | A polished memo/report that imports analysis from owning workstreams |
| Build or update a model | `Use these source financials to create model-ready schedules and an updated workbook.` | `financials-normalizer` | A model-ready workbook or source-to-cell input pack with evidence and QA flags |
| Run pitch or report QC | `Review this transaction deck for source support, consistency, and circulation readiness.` | `ib-deck-qc` | A QC report with findings, severity, and remediation next steps |

## Source Setup

Investment Banking uses configured apps and files when they are available and authorized:

| Source category | What it covers |
| --- | --- |
| Deal Materials | CIMs, teasers, VDR/Datasite exports, diligence documents, management materials, and source packets |
| Process Updates | Trackers, meeting notes, emails, internal messages, deadlines, bids, and process history |
| Relationship & Counterparty Context | Buyer, investor, lender, sponsor, issuer, advisor, and relationship context |
| Market Data & Public Sources | Filings, trading data, estimates, ratings context, market data, and transaction benchmarks |
| Models, Workbooks & Templates | Existing models, workbook extracts, spreadsheet inputs, templates, and model-ready schedules |

Connected tools are useful, but they are not required for every task. The plugin scopes source setup to the selected workflow and falls back to uploaded files, pasted material, exports, and public evidence when appropriate.
