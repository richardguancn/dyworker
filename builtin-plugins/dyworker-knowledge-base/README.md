# 知识库

本插件基于 [dsh-knowledge-base](https://github.com/htcqp802/dsh-knowledge-base) 0.1.5，保留其 MIT 许可。资料保存在应用的数据目录中，可从全局设置中的「知识库」导入、检索、分类和删除，也可由任务调用知识库工具。

页面支持 md、txt、json、yml、docx 和 pdf，单个上传文件不超过 20 MB。同名文件重新导入会替换旧内容。PDF 需要包含可提取的文字，扫描图片暂不能识别。Word 和 PDF 解析已包含必要依赖；未接入上游的 AI 自动整理功能。

知识库直接读取个人和项目记忆，可在页面浏览并与导入资料一起检索；记忆仍在原有的「记忆」中修改和删除。任务检索时，项目记忆只对对应项目可见。会话记忆仍只在原任务中使用，不加入知识库；内置模型认知不作为个人记忆展示。

知识库首页提供关系图谱：每条记忆和每份导入资料显示为一个节点，按具体分类和共同内容分组着色。虚线表示根据共同内容发现的相近关系，实线表示手动添加的关联；可以搜索、筛选、缩放、查看正文以及添加或解除关联。任务检索也会补充适用范围内的相关内容。

「整理记忆」会合并内容完全相同的记忆；配置可用模型后，还会尝试合并含义相同的重复表达，并列出需要确认的冲突。整理记录保留最近 10 次的对照和恢复入口；如果整理后记忆已有新增或修改，将不能直接恢复，以免覆盖后续内容。

可在设置的「记忆」中导出记忆数据，在「知识库」的资料目录中导出解析后的资料内容，在图谱中导出完整图谱数据或当前画面的 PNG 图片。数据文件为 JSON；资料导出不含原始上传文件。当前提供导出查看，尚未提供从这些文件恢复数据的功能。
