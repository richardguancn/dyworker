# 机器人团队（DS Bot）

内置到 DYWorker 的 DS Bot 适配版。无需从 GitHub 另行安装，可在插件页启停；左侧“项目”后面的“机器人团队”入口用于打开团队页面，停用插件后隐藏。

模型沿用 DYWorker 的模型设置。首次打开未配置模型时，只创建总管，不自动发起模型请求；请为机器人选择模型后使用。对话、成员、群聊、记忆及用量保存在 DYWorker 数据目录的 `ds-bot/` 下，与普通任务分开。

## 已接入

- 新建和编辑机器人，配置名称、角色、工作说明、模型，设置总管。
- 机器人对话、机器人提问及用户回答、停止回复；消息排版和输入框沿用普通会话样式，支持复制消息、Enter 发送、Shift+Enter 换行。
- 群聊输入 `@` 选择成员，或选择“所有人”；支持点击选择、方向键切换、Enter/Tab 确认、Esc 关闭列表。
- 当前窗口内保存每个对话的未发送草稿，切换聊天或返回普通任务后可恢复。
- 新建和编辑群聊，选择成员与管理员；管理员协调或成员依次回复。
- 查看、整理及移除机器人记忆，查看团队模型用量。
- 继承 DYWorker 任务的工具能力（见下节），需要确认的操作在「机器人团队」面板点「允许」或「拒绝」。
- 关闭面板和重启后继续使用；插件停用时释放机器人运行。

## 继承 DYWorker 任务的工具能力

机器人可以像普通任务一样读写工作文件夹里的文件、运行命令、联网检索和导出办公文档。工具说明与参数直接沿用 DYWorker 自己的那套定义，执行也走同一批实现：

- 文件：列出、查找、全文检索、读取（含 PDF/Word/Excel/PPT 文字提取）、写入、局部编辑、追加、新建文件夹、复制、移动、删除、敏感信息扫描、公文格式检查。
- 运行：在工作文件夹里执行本地命令（长驻服务可转到「后台任务」面板）。
- 联网：网页搜索、政府网站搜索、读取公开网页、图片与扫描件识别（GLM-OCR）。
- 产出：当前日期时间、导出 Word/Excel、办理时限计算。
- 知识与记忆：工作模板（列出、读取、保存、改进）、写入一路与桌面任务共用的长期记忆、历史任务检索。
- 其他：会话检索（列出/搜索/读取历史会话）、插件工具（plugin__*）与 MCP 工具（mcp__*）。

权限沿用桌面任务那一套，不做第二套判断：内置钩子 + 用户/工作区钩子 + 常驻允许规则 + 你的审批模式（互动、替我审批、自动、完全访问、仅只读）。工作文件夹里的写入按当前模式放行；工作区外的路径、删除、越界或触发钩子的操作会要求确认，需要人工确认时在「机器人团队」面板弹确认卡，审核助手无法定夺时也会转到这里。

机器人默认有自己的工作文件夹（DYWorker 数据目录下的 `ds-bot/workspace`），工作区外的文件按单次确认处理。

以下桌面能力暂未接给机器人：右侧文件预览（open_file）、浏览器面板操作（browser__*）——它们绑定「当前任务」的右侧面板，机器人没有对应会话面板；`update_plan`、`sleep_until`、`finish_task`、`dispatch_agent`、`ask_user` 属于任务回合与计划面板语义，机器人沿用自己已有的子任务与提问机制。

此适配版保留上游的团队运行代码，使用 DYWorker 的主区域面板。上游整套主界面、GitHub 连接、独立浏览器、凭据面板及定时任务管理页面未接入；不导入上游的独立网页搜索插件。机器人可用工具以该团队运行环境实际提供的工具为准。

## 2026-10-13 更新

内置运行代码由 0.1.0 更新到上游最新发布版 0.1.4，保留 DYWorker 的界面、模型配置、工具与审批入口，以及原来的数据目录。升级检查覆盖旧版成员、模型选择、聊天、群聊、记忆和用量的保留。

已同步上游的群聊工作交接、重启后继续未完成工作、时间提示、记忆整理及团队文件保存修复。另修复适配界面在长对话进入后续部分时读不到最新回复、运行状态和停止操作仍指向最初部分的问题。

上游新加入的独立“能力库”管理页面及其技能/MCP 加载服务尚未接入；模型不会收到对应的管理工具，继续使用 DYWorker 已配置的工作模板、插件与 MCP 工具。上游每个机器人的独立权限、思考级别选择界面也未接入，权限继续沿用应用设置。

## 2026-10-29 更新

内置运行代码更新到上游正式版 0.2.3（2026-10-27 发布），继续沿用 DYWorker 的团队界面、模型设置、工具、操作确认和原来的数据目录。

同步了机器人间工作交接与结果恢复、重复请求识别、群聊消息补发、记忆保存恢复、角色和工作说明变更在后续回复中生效，以及长对话早期记录读取等改进。

上游独立桌面应用的系统托盘、头像管理、浏览器接管和 `show_view` 交互卡片未接入此团队面板；需要用户选择时继续使用已有的提问功能。插件保持默认关闭，由用户手动启用。
