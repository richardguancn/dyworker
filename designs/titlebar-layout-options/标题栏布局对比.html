极简拖带

参考：Raycast / Linear

标题栏不再承载会话标题——收缩成一条 36px 的窄拖带，只剩侧栏开关和通高贴边的窗口按钮。会话标题回归内容区页眉，信息分层更干净。

优点

  • 窗口按钮独占一行右端，和应用图标零混淆，截图里的拥挤感彻底消失
  • 36px 窄条给内容让出垂直空间，窗口显得更高
  • 标题只在内容区出现一次，不再与侧栏「最近」列表里的高亮项重复

取舍

  • 侧栏收起时，需要拖窗口的位置偏小（中间仍是拖拽区，但视觉上没有提示）
  • 标题离开窗口顶部，远距离扫视定位当前任务稍弱

macOS 适配

  • 红绿灯嵌入窄条左侧，结构完全不变，只换左侧 padding
  • 36px 窄条与 macOS 红绿灯比例协调（VS Code 同款做法）
B

居中命令胶囊

参考：VS Code Command Center

会话标题从一行死文字升级为居中的胶囊按钮：显示当前任务，点击弹出会话快速切换（等价 ⌘K / Ctrl+K）。左右两段用 Grid 锁死对称，窗口按钮作为独立通高簇贴右缘。

优点

  • 胶囊是绝对视觉中心，标题不再"漂"，左右无论放多少按钮都对称稳定
  • 标题变成入口：点击即切换/搜索会话，一个元素同时解决展示与导航
  • 窗口按钮与应用按钮之间有分隔线 + 通高簇，两组功能一眼分清

取舍

  • 需要实现会话快速切换浮层（工作量最大的一项，但本身也是功能增量）
  • 超长标题受胶囊 max-width 限制，必须省略号截断

macOS 适配

  • Grid 三段式天然兼容：左侧换成红绿灯，胶囊依旧居中，右侧只剩面板开关
  • 与 macOS 原生"居中标题"习惯一致，是三个方案里跨平台观感最统一的
C

标签页

参考：Arc / 浏览器标签条

标题栏本身就是会话标签条：每个进行中的任务是一枚标签，可切换、可关闭、可新建。窗口按钮通高贴右缘。多任务心智最强，和侧栏「最近」列表互为长短横跳。

优点

  • 多任务一目了然，切换/关闭/新建都在一行内，不需要展开侧栏
  • 标签天然居左排列，右端只剩窗口按钮，重心问题不存在
  • 标签条底色与窗口体分层（灰底 + 白色活动标签），信息层级最丰富

取舍

  • 改动最大：会话模型要支持多开并存（当前是单会话 + 列表切换）
  • 只有一两个任务时，标签条显得空旷，需要好的空态设计

macOS 适配

  • 红绿灯嵌入标签条左端（Arc 浏览器同款），标签顺延，结构不变
  • macOS 用户对标签条心智零学习成本

本方案的修正点

  • 铃铛（审批箱）+ 机器人放在「收起侧栏」右侧，左 3 图标 vs 右 1 图标 + 3 窗口按钮，两端重量对称
  • 审批箱带未读角标（沿用品牌橙色），有待办时一眼可见
  • 窗口按钮做成通高、贴右缘的独立簇，与圆角图标之间留 10px 空隙，不再挤成一串
  • 48px 高度、标题位置、拖拽区域全部不动；macOS 下左侧让位红绿灯，其余不变

所有方案共同的底座：窗口按钮在任何方案里都做成「通高、直角、贴右缘」的独立簇（Windows 惯例），与应用内圆角图标在样式和空间上都分开；macOS 下同一结构把左端换成红绿灯即可。点右上角切换平台可逐一验证。
