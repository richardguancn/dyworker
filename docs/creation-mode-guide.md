# DYWorker 创造模式使用指南

**创造模式**让你在 DYWorker 里不用懂任何代码或技术概念，只用平时说话的大白话告诉助手你想要什么功能，就能在几分钟内现场做出专属于你的看板页面、随手小工具或自动化助手能力。

---

## 一、三步用起来（零技术门槛）

### 方法 1：点一下开关直接说想法
1. 在输入框左下角点击 **「创造模式」** 开关；
2. 像对同事提需求一样说出你想要的功能（如果是空对话，还可以直接点卡片示例一键填入）；
3. 需求比较笼统时，助手会弹出 1 轮简单的选择题（如“放左侧独立页面还是右侧随手栏”“每周手动导还是自动更新”），你点选即可，剩下的全部由助手完成。

### 方法 2：一条指令直接开始
- 在输入框里直接输入 `/create 你的想法`（例如：`/create 帮我做一个每周导入 Excel 就能更新的周报看板`）发送即可；
- 也可以单独发 `/create` 来开启或关闭创造模式。

### 方法 3：普通聊天顺手沉淀
- 平时让助手整理出一套表格、工作清单或分析框架时，如果它觉得适合变成常驻功能，会在回答最后附上一张推荐卡片；
- 你选好想放的位置，点 **「立即创建」** 即可在后台做好并挂上界面，不满意还能随时撤销。

> **也可以从插件页进入**：在左侧 **「插件 → DSH 插件 → 制作插件」** 弹窗里写下需求并选择希望放置的位置。

---

## 二、最省事的秘诀：直接发你的报表样本或截图

很多时候自己也说不清报表里有哪些列、该怎么画图，**手头有上一周的文件或截图就够了**：

1. 打开 **「创造模式」**；
2. 把系统导出的 **Excel / CSV 报表** 或 **界面截图** 直接拖进输入框（或用 `@` 引用进来）；
3. 只发一句话：**“照着这份报表，帮我做一个每周导入新文件就能自动更新的独立看板页面，能看核心指标、上周对比和趋势图。”**

助手会自动看懂表头结构，替你做好数据导入、历史留存、趋势统计图和界面排版。

## 三、你能用它做出哪些功能？（大白话案例清单）

以下案例的提示词都不含任何技术词汇，你可以直接复制修改后发给助手：

### 1. 每周系统报表看板（适合放在「左侧独立页面」）
适合需要大画幅看指标、查历史周环比和趋势折线的定期汇报场景。

> **直接这样说：**
> “我每周会从业务系统导出一份 Excel/CSV 报表，请帮我做一个单独的周报看板页面：能看本周关键指标和相比上周的变化，自动画出近几周趋势图和分类占比图，并且支持每周导入新文件或配合定时任务自动更新数据。”

- **想实现全自动每周更新？** 做完看板后，再去左侧 **「定时计划」** 建一条计划：
  - **目录变更触发**：指定系统导出文件存放的目录，以后文件一放进去，软件自动识别新报表并更新看板数据；
  - **每周定时执行**：设定每周固定时间（如周一早 8:30）让助手自动汇总最新数据并写入看板。

### 2. 项目进度看板（适合放在「左侧独立页面」）
> “帮我做一个单独的项目进度看板页面：把工作按待办、进行中、已完成三列管理，支持随时新建、修改状态、按截止日期筛选，顶部配一个状态分布统计图，关闭软件后数据也不会丢。”

### 3. 文档审校自查清单（适合放在「右侧随手工具」）
适合放一条在对话框旁边，边让助手写稿、边自己逐项打勾核对。
> “帮我在对话框右侧加一个随手可打开的「文档审校自查清单」小面板：内置公文、周报汇报和合同三组检查项，支持一边写内容一边勾选打勾、显示完成进度，也能自己增删检查条款并一键重置。”

### 4. 常用话术与模板库（适合放在「右侧随手工具」）
> “帮我在对话框右侧做一个「常用话术与模板库」小工具：可以按场景分类保存我常用的回复、会议通知和汇报模板，支持按关键词快速搜索、随时新建修改，点一下就能复制到剪贴板。”

### 5. 会议行动项追踪（适合放在「会话顶部视图」）
> “帮我在对话顶部新增一个「会议行动项追踪」切换视图：方便我直接记录每次讨论定下的待办事项、负责人、优先级和截止时间，支持按完成状态筛选和一键标记完成，内容持久化保留。”

### 6. 格式清洗与文件编号助手（仅增强助手能力）
> “帮我给助手新增两个实用小工具：一个是自动清理文稿里多余空行、统一中英文标点，另一个是按日期前缀自动生成规范的文件编号。做完后帮我试跑验证一下，以后我直接让你用就行。”

## 四、做好之后怎么改版、管理和保障安全？

- **想改界面或加功能怎么办？**
  保持在 **「创造模式」** 下继续提意见就行（比如“把逾期任务用红色标出”“再加个导出汇总按钮”），助手会直接修改源码并热刷新界面，不用重启软件。
- **做出来的东西存在哪里、怎么安装、停用或重装？**
  - 在 **「创造模式」** 下做好的纯本地功能，通过安全检查后会自动安装并立即打开使用，无需手动配置；
  - 默认统一保存在应用受管插件目录中（如果你想跟着某个项目目录走，建的时候选一下那个工作文件夹即可）；
  - 打开左侧 **「插件 → 扩展插件」**，所有自制功能都能随时关闭、重新开启或卸载；如果之前卸载了或手头有本地插件文件夹，点右上角 **「安装本地插件」** 可在 **「我创建的本地功能」** 中一键重装打开，或点击 **「选择文件夹…」** 直接导入；通过推荐卡片做出来的还支持 **「撤销（保留源码）」** 和 **「一键恢复」**。
- **安不安全？**
  - 所有页面和工具都在你自己的电脑本地生成与运行，不会发布或上传到任何外部网站；
  - 创造模式下仅自动放行受管目录内、无需联网拉取第三方依赖的纯本地新功能安装；其余插件、外部目录或卸载操作仍会经过安全检查并由你确认后生效。
