# Claude Mods 桌面验收记录

## 完成标准与检查清单

按用户要求保留 DSH 插件支持层，建立来源、许可、固定版本和场景匹配明确的精选列表。Claude Mods 首期仅提供已经实现并验证的能力，未支持能力必须明确失败。

| 可见功能或交付声明 | 操作检查 | 需要检查的显示状态 |
| --- | --- | --- |
| DSH 与 Claude Mods 独立管理 | 两种插件切换，返回原页面 | 原有 DSH 清单仍正常，Mods 有范围提示 |
| 精选清单 | 已安装、可安装切换；搜索匹配和无匹配 | 三项名称、版本、来源、许可、适用范围 |
| 安装 | 逐项点击安装 | 安装后出现在已安装；重复安装不可点 |
| 设置 | 保护目录改为“归档”，保存，再改回 | 保存后重新进入页面仍保留设置 |
| 启停 | 每项停用，再启用 | 按钮及状态文字同步；停用面板移除 |
| 活动面板 | 打开当前任务活动，点击清空 | 计数与清空按钮可见；清空后计数为零 |
| 卸载 | 卸载再安装，检查重启恢复 | 清单和任务面板无残留；保存状态恢复 |
| 本地添加 | 选择真实文件夹并安装 | 支持代码可用；不支持代码有具体错误 |
| 原件保护 | 默认任务和 DSH 任务分别真实写入原件及副本 | 原件内容不变；副本实际生成 |
| 上下文余量 | 无读数、估算读数、真实读数分别检查 | 无读数不编造；估算有标记，真实读数无估算标记 |

另外检查：无匹配搜索后清空搜索恢复列表；安装过程中切换页面；停用前取得的按钮在启用后不能操作新实例；小窗口下按钮和说明不被裁切。实际文件写入、并发数据保存、出错后的恢复与取消通过代表性自动检查覆盖。
