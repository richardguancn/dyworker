## 上下文仪表盘重复弹出修复

完成标准：关闭一次后，宿主刷新、插件重新登记、任务切换及应用重启均不会再次添加；用户可以从右侧 + 菜单或空面板菜单手动打开，且同一插件页面最多一个标签。

原因：右侧插件插槽的全量同步把所有已注册但未打开的页面再次加入标签，关闭操作没有保存用户选择。此外，设置页重新启用插件也会发出主动打开请求。

处理：独立保存被关闭的插件页面，登记/启用与主动打开区分；右侧菜单列出可用插件页面；同步去重并保留其它页面及其顺序。关闭偏好覆盖所有任务，主动打开撤销该页面的关闭偏好。

验证：
- `npm run build:renderer` 通过。
- `node --test tests/plugin-panel-tabs.test.mjs tests/panel-layout.test.mjs tests/plugin-client-host.test.mjs tests/builtin-plugins.test.mjs`：24 项通过。
- 实际 Electron 测试窗口：关闭仪表盘一次，停用并重新启用上下文插件，回到任务后没有仪表盘标签；通过 + 菜单手动打开只产生一个仪表盘，再次关闭后保持关闭。
- 实际新建任务、切回原任务：仪表盘保持关闭，原文件面板正常恢复。
- 关闭并重新启动独立测试窗口：仪表盘保持关闭；截图 `context-dashboard-closed-after-restart.png`。
