# DS Bot 内置接入

2026-10-11 接入 `ds-bot@0.1.0`，上游提交 `351ae74b1c1bef0c21bf914a2687046a526190ee`。

## 使用

打开右侧“打开侧边操作”菜单，选择“机器人团队”。在 DYWorker 模型设置中配置模型后，编辑总管选择模型，即可发送消息。创建第二个机器人后可以新建群聊，至少选择两位成员；群聊编辑页可设置管理员、群公告和回复方式。机器人“记忆”页面可以查看及整理记忆，“用量”页面显示团队累计用量。

插件页可停用或重新启用“机器人团队”。对话、群聊、记忆保存在 DYWorker 数据目录的 `ds-bot/` 中。无需重新安装 GitHub 仓库，不使用失败安装的 staging 目录。

## 接入范围

保留上游团队运行代码，按 DYWorker 的模型设置提供模型，单独持有团队会话与保存目录，并在现有右侧面板提供操作界面。上游目录原样文件已逐一比对，28 个文件的来源和 SHA-256 记录在 `builtin-plugins/ds-bot/sources.json`；许可证及版权声明一并保留。

本适配版未接入上游整套主界面、独立浏览器、GitHub 连接、凭据面板或定时任务管理页面。模型工具列表也不提供会声称打开凭据卡片的工具。网页搜索插件未导入。可用功能详见 `builtin-plugins/ds-bot/README.md`。
