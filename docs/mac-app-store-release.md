## 已添加的发布基础配置

- `build/mac-app-store.cjs`：独立商店目标，强制正式签名，关闭向现有下载渠道发布，产物输出到 `output/mac-app-store`，不替换普通版配置。
- `build/entitlements.mas.plist` 与 `build/entitlements.mas.inherit.plist`：苹果隔离运行权限、联网、本地服务、用户选择的文件读写及语音输入所需麦克风权限。配置中加入麦克风和应用操控的用途说明；用途说明本身不表示已经取得系统权限或能绕过隔离限制。
- 描述文件通过 `MAS_PROVISIONING_PROFILE` 指定；构建编号通过 `MAS_BUILD_NUMBER` 指定。不在仓库保存证书、私钥、账号密码或描述文件。
- `node scripts/mac-app-store-preflight.mjs` 只读检查发布环境。`--json` 输出结构化结果；退出码 1 表示环境未准备齐全。退出码 0 只表示本机环境检查通过，应用适配、账号、协议、材料及审核仍须另行确认。
