## 修复建议

1. 每项成功声明分别核对；某项“尚未上传”不能免除另一项成功声明的核验。覆盖中文文件名和混合陈述。
2. 操作是否产生写入应来自实际执行结果，不能来自工具名称；读取草稿不是上传。核对具体目标、数量和成功回执。
3. 文件证据使用完整规范路径，并证明本次写入或修改；旧文件存在、任意命令成功不能替代写入证据。
4. 普通聊天、后台继续、定时唤醒等恢复入口统一保留并正确还原完整操作链。
5. 服务端错误按字段过滤，或仅展示允许的错误类别；正则无法可靠遮盖所有常见 JSON 凭据格式。
