DYWorker 0.1.17 版本正式发布。相比 0.1.16，这一版本围绕「技能生态、多模态输入、任务可控性、日常体验」四个方向做了集中打磨，累计提交 60 余次，代码变更超过 1.2 万行。下面挑重点和大家聊聊。

![【截图占位符：0.1.17 版本主界面 / 关于页面】](imgs/cover.png)

## 接入 SkillHub 技能库

本版本最重要的变化之一：DYWorker 接入了 SkillHub 技能库，并内置了技能列表与搜索能力。

- 在应用内即可浏览、搜索技能库中的技能，按需安装启用；
- 技能搜索框样式也做了专门优化，查找更顺手；
- 技能与任务流程打通，装完即用，无需手工配置目录。

![【截图占位符：技能库列表与搜索界面】](imgs/skillhub.png)

## 图片能力大幅增强

- **支持粘贴剪贴板图片**：截图之后直接在输入框粘贴，即可作为附件发送给模型；
- **DeepSeek V4 图片识别**：接入 DeepSeek V4 的 Responses API，默认模型切换为 DeepSeek V4，支持图片理解；
- **回复中显示本地图片**：任务产出的图片可以直接在对话里预览，并优化了图片附件的预览样式。

![【截图占位符：粘贴剪贴板图片发送的示例】](imgs/clipboard-image.png)

## 浏览器协作改为右侧面板

浏览器协作从独立窗口改为应用内的右侧面板：网页打开、点击、填表、截图的全过程都在任务窗口右侧实时可见，不再需要来回切换窗口，人机协作更连贯。

![【截图占位符：右侧浏览器协作面板】](imgs/browser-panel.png)

## 多任务与停止机制更可靠

这一组改动不太显眼，但直接影响日常使用的安心程度：

- 修复多任务会话并发问题，完善并发任务之间的隔离；
- 支持**立即停止**模型请求，保留排队操作的停止状态；
- 收紧停止后的任务边界——任务停止后不再写入记忆，修复任务完成后工作计划状态未收口的问题。

## 工作区与审批体验优化

- 优化工作区上下文与新建任务体验，工作区列表功能可复用；
- 增加工作目录快捷操作，标题栏按钮改为悬停显示，界面更干净；
- 优化审批模式与自动审核，补充完整的访问权限确认，并修复了无工作目录时的审批提示问题；
- 增加首次身份选择功能，新用户上手更顺畅。

## 更多细节

- 支持自定义应用更新地址，并接入 GitHub 标签自动更新；
- 完善多轮对话上下文，长对话更稳定；
- 完善消息操作与 Markdown 预览，优化消息操作和界面字体；
- 支持回复中渲染可视化展示效果；
- Linux 下窗口布局、阴影与打包问题修复，Windows 路径分隔符兼容修复；
- 内置「模型能力边界」记忆，助手在推荐模型时能分清模型能力与产品能力。

## 升级方式

打开 DYWorker 即可收到 0.1.17 的更新提示；也可以在设置中配置自定义更新地址，或前往项目主页下载最新安装包。
