DYWorker 0.1.21 版本正式发布。相比 0.1.20，这一版本把重心放在「渠道能力、登录态迁移、任务可靠性、授权体验」四个方向，累计提交 21 次，涉及 39 个文件，新增代码 4800 余行。下面挑重点和大家聊聊。

![【截图占位符：0.1.21 版本主界面 / 关于页面】](imgs/cover.png)

## 微信/QQ 渠道：从「发文字」到「传文件」

这是本版本最大的亮点。DYWorker 的微信、QQ 渠道不再只能收发文字，现在可以像面对面办公一样传文件：

- **收图片**：把截图、照片直接发给助手，它就能看懂内容并据此干活；
- **收文件**：把表格、文档发给助手，落地后进入任务上下文，桌面会话同步显示文件名和缩略图；
- **收语音**：发一段语音，自动转写为文字进入任务，不用再打字；
- **发回来**：任务产出的图片、文件也能通过渠道回传给手机端。

文件大小上限 50 MB，超出会明确提示。整条媒体消息链路（下载、转写、回传）都做了加固，QQ 富媒体发送还会自动重试过期消息 ID，出站路径也加了校验，防止文件逃逸出工作区。

![【截图占位符：微信/QQ 渠道收发图片、文件、语音的示例】](imgs/channel-media.png)

## 远程操控：手机上也能指挥任务

渠道不只是「聊天」，现在更像一个随身控制台：

- **更换工作目录**：在微信/QQ 里直接发「更换工作目录至 …」，即可切换该聊天当前的操作目录，不用回到电脑上改；
- **停止任务**：任务跑偏了，手机发指令即可停下；
- **输入提示与分片上传**：长消息自动分片，避免超长内容被截断；输入时给出提示，交互更顺畅；
- **右键编辑菜单**：排队中的消息可直接编辑，「调整方向」改名为更直观的「立即执行」。

![【截图占位符：渠道「更换工作目录」指令与任务停止操作】](imgs/workdir-command.png)

## 浏览器登录态一键迁移

继续完善浏览器数据导入能力。这个版本新增 **localStorage 导入**，像 kimi 这类把登录态放在 localStorage 的新式站点，现在也能随导入一起迁移了：

- 导入的登录态**跨重启保留**，不用每次都重新登录；
- 会话级 Cookie 会自动补上有效期，避免导入后很快失效；
- 顺带修复了历史导入用 32 位整数读大时间戳导致的溢出问题（改为 BigInt 读取）。

![【截图占位符：浏览器站点数据导入（登录态迁移）界面】](imgs/browser-import.png)

## 任务控制与模型补强

这组改动不显眼，但直接决定任务能不能「一次跑对」：

- **网络抖动自动重试**：模型请求遇到瞬时网络抖动会自动重试，不再一抖就报错；
- **补齐 V4 Pro 视觉识别**：完善了 V4 Pro 模型的图片理解实现；
- **工具参数前置校验**：工具调用前先按声明的 JSON Schema 校验参数，非法参数在审批和执行前就被拦下，减少中途失败；
- **截断保护**：模型输出被长度上限截断时，不再盲目执行其中的工具调用，避免「半截指令」被执行；
- **技能渐进披露**：工作模板（技能）改为渐进披露，只在需要时才展开说明，提示词更精简、响应更聚焦。

## 授权与审批体验优化

- **外部路径授权延续**：本人批准过的工作区外路径，在本次任务内持续有效（含其子路径），不用反复弹窗确认；
- **替我审批更聪明**：开启「替我审批」后，工作区外路径的放行改由审核助手按上下文判断，而不是一刀切。

## 升级方式

打开 DYWorker 即可收到 0.1.21 的更新提示；也可以在设置中检查更新，或前往项目主页下载最新安装包（支持 Windows x64、macOS Apple 芯片、Linux ARM64 / 麒麟等）。
